# KOVAX · Bitácora 2026

Bitácora del proyecto KOVAX: prototipo de horno eléctrico automatizado. Sitio estático en HTML, CSS y JavaScript, inspirado en la organización documental de Fab Academy (sin afiliación).

## Cómo usar
1. Descomprime el ZIP.
2. Abre `index.html` con un navegador (no requiere servidor).
3. Edita cada página en `semanas/semana-01.html` hasta `semana-16.html` para sustituir los marcadores por evidencias reales.
4. Guarda fotos en `assets/images/` y documentos en `assets/docs/`. Vincúlalos con rutas relativas.
5. Para publicar: sube el contenido a GitHub Pages, Netlify u otro hosting estático.

## Páginas
- `index.html`: inicio y resumen.
- `semanas/index.html`: listado, búsqueda y filtros de 16 semanas.
- `semanas/semana-01.html` ... `semana-16.html`: página autónoma semanal con navegación entre semanas.
- `proyecto.html`: proyecto final.
- `documentacion.html`: biblioteca de entregables (marcadores vacíos).
- `equipo.html`: cuatro roles funcionales.

## Tecnología
CSS responsive con modo claro/oscuro y menú móvil. JavaScript sin dependencias. Fuentes Google Fonts con fallback local.

## Precisión
El sitio usa datos generales del proyecto y el cronograma previsto de 16 semanas; no afirma que existan resultados experimentales. El SVG principal es una ilustración no un plano eléctrico.
